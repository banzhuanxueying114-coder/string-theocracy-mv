## 分工与下一轮复测

- **保留 Sonnet 做首轮审图，Sol 做执行。** Sonnet 对正确安装座和细裂纹的判断可以减少无谓返工。它仍会漏过三只脚，也会误拒实际采用的教徒和主圣像。Sol 能定位露脸教徒和井道人物，底座安装面和玻璃分块的反向误判使它的验收结论需要复核。现有 Sonnet／Opus 段落分工仍按交接执行，这组报告没有 Opus 对照数据。 [模型分工](<../HANDOFF.md#L13-L24>)
- **审核要查实理由。** 把「采用标签吻合」与「定位到去留的关键原因」分别计分。img1 的 Sol 标签吻合，但没有定位已知退回原因。img2 的底座和钥匙是分层素材，报告对合成阶段提出的检查意见不能直接否决底图。img4 的动作证据依赖同机位配对，缩略图下分不清可记「需配对确认」，并同时记录兜帽条件已过。手脚、关节、花饰、背部底座和玻璃铅条进入原尺寸复核。 [人设核对清单](<../HANDOFF.md#L43-L56>)
- **复测用新样本和统一输入。** 由主会话先记录镜头用途、必过条件、可接受瑕疵及对应局部证据，隐藏历史去留并随机打乱顺序。两边使用同一参考版、整图和原尺寸局部，给动作换姿态题成对图。要求输出「通过／退回／需放大或配对」、图中位置及触发条款。分别记录硬伤误放行、可用素材误拒、理由对齐和待确认数量，另看两者都错的成对题。用新批次检验这套做法，避免仅重做已经知道答案的八张。
